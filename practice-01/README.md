## 5. Задание 2. Исследование типов и преобразований

Столбцы «Фактическое значение» и «Тип результата» получены запуском `node practice-01/js/types.js`.

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"`, строка | `82` (строка `"82"`) | string | Оператор `+`, если один из операндов строка, выполняет конкатенацию: число 2 преобразуется в строку и дописывается. |
| `"8" - 2` | 6, число | `6` | number | У оператора `-` нет строкового смысла, поэтому строка `"8"` преобразуется в число. |

| `"12" > "3"` | `false` | `false` | boolean | Две строки сравниваются посимвольно, а не как числа: первый символ `"1"` меньше `"3"`. |

| `Number("text")` | `NaN` | `NaN` | number | Строку нельзя разобрать как число, результат — «не число». `NaN` сам имеет тип number. |
| `Boolean("false")` | `true` | `true` | boolean | Любая непустая строка при логическом преобразовании даёт `true`, независимо от её содержимого. |
| `typeof null` | `"object"` | `object` | string | Историческая особенность языка: `typeof null` возвращает `"object"`, хотя `null` не объект. Сам результат `typeof` всегда строка. |
| `typeof NaN` | `"number"` | `number` | string | `NaN` относится к типу number. Результат выражения `typeof` — строка. |

## 7. Отладка (`debug.js`)

**Исходная версия** (с намеренными ошибками) при запуске `node` выдала:

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

Эти значения неверны (ожидалось 5, 3 и 10), хотя исключений программа не выбросила.

**Исправленная версия** выдаёт:

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `Выполнено: 32`, `Осталось: -24` | `completedText + additionalText` — это сложение двух строк, то есть конкатенация `"3" + "2" = "32"`. Затем `"8" - "32"` преобразует обе строки в числа и даёт `-24`. | Явное преобразование: `Number(completedText) + Number(additionalText)` и `Number(plannedText) - completedTotal`. | `Выполнено: 5`, `Осталось: 3` |
| Граница цикла | `Контрольная сумма: 6` | Условие `taskNumber < 4` останавливает цикл до номера 4, суммируются только 1, 2, 3. | Условие заменено на `taskNumber <= 4`. | `Контрольная сумма: 10` |

Исходные строки с ошибками:

```js
const completedTotal = completedText + additionalText;
for (let taskNumber = 1; taskNumber < 4; taskNumber += 1) {
```

**Остановка программы отладчиком.** Исходная версия `debug.js` открыта в браузере, точка останова поставлена на строке 8 (`const remainingTasks = ...`), то есть после вычисления `completedTotal`. Значения в момент остановки получены через отладчик браузера (вычисление выражений в текущем кадре вызова):

| Выражение | Значение при остановке |
|---|---|
| `completedText` | `"3"` |
| `additionalText` | `"2"` |
| `completedTotal` | `"32"` |
| `typeof completedTotal` | `"string"` |
| `plannedText - completedTotal` | `-24` |

По этим значениям видно причину: `completedTotal` уже строка `"32"`, значит, ошибка возникла раньше, на строке со сложением двух строк. Скриншот окна DevTools в архив не включён, вместо него приведены значения из отладчика.
